# 陈洁斌主号 · 目录说明

一条视频 = 一套（S01、S02……）。**每套自己的文案、音频、成片、过程各自独立命名、独立文件夹。**

## 总目录

| 目录 | 放什么 | 生命周期 |
|---|---|---|
| `01_人设与规范` | 人设圣经、背景设计方案、ComfyUI 插件速查 | 长期，改了要同步 |
| `02_素材真值` | 形象底图、声音参考 flac/逐字稿、定版静帧 | 长期真值，不随套次变 |
| `03_生产脚本` | 出静帧 / TTS / 视频 / 配乐 / 混音 / 收尾 的 py | 长期，每套复用 |
| `04_验收工具` | ASCII 判图、接缝、景别、油光、音轨 检查 | 长期 |
| `05_文案` | 每套一个 `Sxx_名字/` | 按套 |
| `06_音频` | 每套一个 `Sxx_名字/` | 按套 |
| `07_成片` | 每套一个 `Sxx_名字/`，含制作记录 | 按套 |
| `08_过程` | 每套一个 `Sxx_名字/`，未调色原片、配乐 wav、抽帧 | 按套，可清 |

## 命名规则

```
S02_不用再折腾_成片_39.9s.mp4        成片（时长写进名字，一眼可比）
S02_不用再折腾.srt                  字幕（跟成片同名，播放器自动带）
S02_音频_定板_39.5s.mp3              定板音频（时长写进名字）
S02_字幕文本.txt                     字幕用的纯文案（无标点歧义，供 make_srt_asr 用）
S02_文案_定稿.md                     文案
S02_未调色原片.mp4                   过程：H3 直出未调色
S02_制作记录.md                      分段表、参数、验收数据
```

时长一律写进文件名：后面复用时能立刻分辨「这版多长、是不是我要的那版」，不用点开。

## 每次开工的顺序

1. **先清理**：上一套的过程文件（未调色原片、临时 wav、抽帧）检查是否还有复用价值，没有就 `gio trash`。已经交付进 `07_成片/` 的不动。
2. 新套次建三个文件夹：`05_文案/Sxx_名/`、`06_音频/Sxx_名/`、`07_成片/Sxx_名/`、`08_过程/Sxx_名/`。
3. 文案 → TTS → 用户确认音频 → 视频 → 后期 → **出字幕** → 验收 → 交付到 `资产/`。
4. 补一份 `Sxx_制作记录.md`。

出字幕的命令（在 `陈洁斌主号/` 下）：

> ⚠️ `make_srt.py` 已废弃，定版流程用 `make_srt_asr.py`（ASR 对齐时间轴，字幕跟人声走，不再靠静音段切句）。

```bash
python 03_生产脚本/make_srt_asr.py \
  06_音频/S02_不用再折腾/S02_音频_定板_39.5s.mp3 \
  05_文案/S02_不用再折腾/S02_字幕文本.txt \
  07_成片/S02_不用再折腾/S02_不用再折腾.srt
```

字幕文本用 `.txt` 纯文案（直接从 TTS 的 TEXT 复制，**保留标点**）——
标点是切条和断行的依据，缺了会切出「换衣服/化妆」这种断词。

**行宽规则（2026-10-27 定板）**：一行 7–12 字最舒服。折行只在标点处断；
没有标点又超过 14 字（竖屏物理上限）时，才用 `make_srt_asr.py` 里的 `MANUAL_BREAK`
语义断点表。13 字这类不折——整行比拆成「11+2」好看。

## 千万注意

- **清理只用 `gio trash`，不用 `rm`**。回收站里还能捞回来。
- 清理前必须 `md5sum` 确认归档副本一致，不一致的不许删。
- `02_素材真值` 里的东西是后续所有套次的基准，**永远不删**。
