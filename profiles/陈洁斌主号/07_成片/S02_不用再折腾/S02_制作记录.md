## 文案正文（TTS 逐字）

```
先跟你说句实话。你不是不会拍，你是每次拍都得换衣服化妆找地方摆灯。上周有个开服装店的姐姐找我，只给了一张照片和十秒录音。二十分钟出片，她看了三遍问我，这真是我吗？我说是你，只是不用你再折腾一遍。你上新换季做活动，哪次不用讲两句？可你没时间。以后你只要录十秒，剩下的我来。私信两个字，分身。我用你自己的声音，免费做一条十五秒的样片，你听完再决定。
```

## 与 S01 的差异

1. **角度从「能力」换成「省事」**：S01 讲"全是 AI 做的"（证明能力），S02 讲"你不用再折腾一遍"（解决痛点）。用户反馈 S01 单调，S02 用行动清单式痛点开场 + 一个客户原话 + 「你不用再做什么」收尾。
2. **景别加了微微动感**：段 1 前 2.5s 极缓退 2%（用户定板「微微的一点动感」），之后锁死。其余 4 段全程锁机位。
3. **手势收敛**：GESTURES 从 S01 的满套减到 9 个，幅度更小（顺着"单调"的反馈往安静方向调，而不是更热闹）。

```

  → finish_v6.py v6_bgm.mp4 v6_final2.mp4                # 曝光 + 压高光
```

- 配乐 `bgm_v6.wav`：88 BPM / C 大调 I-V-vi-IV / 加法合成，与 S01 同一套 but 长度 39.90s
- 配乐增益 **−34 dB**：停顿段 −46.2 dBFS，比人声段（−29.3）低 17 dB，整体 RMS 只 +0.4 dB
- 曝光 `finish_v6.py`：`eq=gamma=1.12:contrast=1.01:saturation=1.02` + `curves` 压高光
  - 帧 p85 186.2→194.4，脸均 116.9→127.5，**>230% 过曝 0.83%→0.77%**（比原片更低）
  - S01 的 `finish_v5.py` 只有 gamma，过曝会升到 1.60% 显油 → S02 起改用 finish_v6

### 时间轴怎么来的（重要）

**不是**按字数均分，也**不是**只靠 ASR。做法是「静音检测 + 块级 DP」：

1. `silencedetect -32dB:0.12` 扫出 28 个发声段（连续发声、内部无停顿），过短的并进邻居
2. 把 19 条字幕**顺序**分配到这些段的连续区间上，代价 =
   `log(该条语速 / 全片名义语速)² + 吃进静音的秒数 × 0.6`
3. 结果：每个边界天然落在真实静音上，精度 ~10ms

试过但不可用的三条路（留档避免重走）：
- **按字数比例切**：累积误差让整条错位，把「我说是你」并进上一句、空出 0.5s 假字幕
- **字级 DP**（152 字分到 28 段）：算出「某段 23 字、某段 1 字」的病态解
- **只用 ASR 句级分组**：句内仍要均分，「我说是你」会从 19.909 起，实际 20.192 才开始

### 本版修掉的三个 bug（都留档，别重犯）

1. **多行 cue 丢第二行**：SRT 读进来是真实换行符，直接写 `.ass` 会被 libass
   当成两行物理数据、只解析第一行 → 「找地方摆灯」整句消失。
   必须转成 `\N` 转义（`make_ass.py: norm_lines()`）。
2. **CTA 出现两次**：原本 `cta_cues=[16,18]`，「免费做一条十五秒的样片」也被算成
   行动号召，稀释了真正的「私信两个字，分身」。改为只留 `[16]`。
3. **半角数字撑开大字距**：「你只需要 10 秒录音」在中文行里会出现巨大空隙，
   改成「你只需要10秒录音」连写。

### 一个渲染层的坑（换标题样式时会再遇到）

标题用了头部 `\t(0,291,\fscx114\fscy114)` 做弹入。如果高亮词里再写 `\fscx104`，
那一段缩放就被钉死在 104，整行放大时它不动 → 一眼看出是贴上去的。
所以标题层的高亮用 `substyle.hlcolor()`（**只改色不碰缩放**），
正文层才用 `substyle.hl()`（变色 + 104% 微放大）。
