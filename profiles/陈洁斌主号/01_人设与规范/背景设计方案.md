# 主号静帧 · 背景设计方案（2026-10-26）

> 白色背景已否决。目标：结合获客文案（AI 分身替商家出片）+ 客群（服装店主）+ 人设（热情亲切、像身边懂技术的朋友），竖屏 1088×1920。
> 用 Qwen-Image-2.1 对 `档案/洁斌_形象底图_1088x1920.png` 做背景替换，人物不动。

---

## 方案 A · 服装店实景虚化（推荐 ⭐）

**为什么**：客户是服装店主，人往店里一站，第一眼就是「自己人」。背景虚化掉店铺细节，真人 Vlog 感最强，也最不像 AI 抠图。

**Qwen 提示词**：
```
把纯白色背景替换为一家现代服装买手店的内部：人物身后是虚化的木质衣架，挂着高级质感的大地色系和深色系成衣，暖色射灯在背景形成柔和光斑，浅景深，背景整体虚化。人物的面部、发型、服装、姿势完全保持不变，人物边缘干净无白边无光晕。真实摄影质感，竖版9:16。
```

**调子**：暖白光（约 4000K），背景明度中等偏深，人物轮廓光弱。

---

## 方案 B · AI 工作室科技感

**为什么**：直接视觉化「AI 分身」主题——身后是屏幕光带和数据氛围，适合片子开头「这条视频里的人不存在」这句悬念文案。

**Qwen 提示词**：
```
把纯白色背景替换为一个深色调的AI数字工作室：人物身后是虚化的深蓝黑色调，几条竖向的屏幕光带发出柔和的蓝白光，点缀细小的光点粒子，地面有微弱的反光。人物面部被前方柔和的暖光照亮，与冷色背景形成对比。人物的面部、发型、服装、姿势完全保持不变，人物边缘干净无白边。真实摄影质感，竖版9:16。
```

**调子**：冷底暖面——背景深蓝黑，人物用暖光，避免科技感压过「亲切带笑容」的人设。

---

## 方案 C · 轻奢会客厅顾问感

**为什么**：把陈洁斌塑造成「来帮你解决问题的顾问」，米色暖调干净高级，适合后续多条视频统一视觉。

**Qwen 提示词**：
```
把纯白色背景替换为一个简约轻奢的会客厅角落：人物身后是虚化的米色墙面和一株大型绿植的模糊轮廓，暖色落地灯光从侧面打亮背景一角，浅景深。人物的面部、发型、服装、姿势完全保持不变，人物边缘干净无白边。真实摄影质感，竖版9:16。
```

**调子**：米色/奶油色 + 暖光，全画面明度最接近原白底，人物打光几乎不用改。

---

## 使用建议

1. 三版各出一张静帧对比，选定后把该方案提示词固化进作战台工作流卡（静帧环节）。
2. 口播开头的「这条视频里的人不存在」悬念段可用 B 做 0-3s 封面帧，成片主体用 A/C。
3. 提示词通则（三版都适用）：
   - 必须写「面部、发型、服装、姿势完全不变」——防止换背景时换脸；
   - 必须写「边缘干净无白边无光晕」——白底替换最常见的翻车点；
   - 必须写「背景虚化 / 浅景深」——背景一实，AI 感和抢镜感都会上来。
