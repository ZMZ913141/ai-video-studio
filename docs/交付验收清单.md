# 交付验收清单

> 起因：2026-10-31 珠珠 Y01/Y02 交付事故。五项技术指标全绿就交了，但成片里
> ①她穿的是产品库里不存在的外套 ②右边货架上挂的是长袍不是短款马甲 ③一句字幕只剩小字副标。
> 三项都没被任何验收工具测出来。

## 一、教训：技术指标 ≠ 内容正确

之前的"验收"只有这些，**全部是格式层**：

| 项 | 工具 | 它能证明什么 | 它**不能**证明什么 |
|---|---|---|---|
| 字幕同步 | `srt_sync_audit.py` | SRT 每句的时间轴与 ASR 对齐 | **ASS 里到底烧了几条**（少一句照样满分） |
| 安全区 | `safe_zone_audit.py` | 文字没越过抖音 UI 保护区 | 文字内容对不对 |
| 音色 | `voice_check.py` | 这条配音像不像本 IP 的嗓子 | 画面里的人是谁 |
| 配乐电平 | `audio_check.py` | 人声比配乐高多少 dB | — |
| 黑帧/静止 | ffmpeg blackdetect | 没有黑屏、没有卡死 | 画面里的东西是不是客户要的 |
| 分辨率 | ffmpeg -i | 尺寸/帧率对不对 | 构图对不对 |

**结论：这六项全绿，片子依然可以是废的。** 它们证明的是"文件没坏"，不是"内容对"。

## 二、交付前必须过的两关

### A. 自动闸门（机器判定，不过不许交）

1. `algo` / `gen_video` DRY：分段数与 `prompts.en.json` 段数一致，无告警
2. `make_ass`：**字幕完整性**——正文轨条数 == SRT 条数 − 开场标题承担条数
   （不满足直接 `sys.exit(2)`，pipeline 会停）
3. `voice_check`：成片音色 vs 本 IP 参考 ≥ 0.90，且不是最像别的 IP
4. `srt_sync_audit`：字幕头尾偏移 ≤ 0.35s
5. `safe_zone_audit`：四边越界 0px
6. `audio_check`：配乐低人声 ≥ 12 dB（<8 听不清）
7. 黑帧 0、长静止帧 0

### B. 内容闸门（人眼判定，必须做）

跑 `content_sheet.py <成片> <静帧> <产品图>`，出一张对照图，逐项看：

| # | 看什么 | 判据 |
|---|---|---|
| 1 | **她穿的是产品库那一件吗** | 颜色块分布、盘扣样式、下摆长度与产品图一致 |
| 2 | **左侧主产品位** | 挂的是同一件，且能看出是"挂着的衣服"而不是一团布 |
| 3 | **右侧货架** | 每件形状与产品图同类（短款就是短款，**不是长袍/长裙/裤子**） |
| 4 | **段间一致性** | 第 1 帧与最后一帧穿的是同一件，没有换装、没有变色 |
| 5 | **产品库溯源** | 能指出成片里的衣服对应 `02_素材真值/产品图库/` 里的哪个文件 |

**第 5 条是硬要求**：如果指不出是哪个产品文件，就说明服装是模型编的，不能交。

## 三、静帧生成的三条硬规则（这次踩的坑）

1. **`--refs` 必须包含产品图库的那一张**。只给人像+背景，模型不知道要穿什么。
2. **提示词里对参考图的指代必须与实际文件一致**。曾经给的是「内搭参考」（四件衬衫），
   提示词却写 "Image 3 is the vest" —— 模型只能瞎编出一件不存在的衣服。
3. **商品形态必须显式约束**。只写 "copies of the same vest" 不够，模型会画成长袍。
   要写：`short sleeveless vests, hem ending at the waist, on wooden hangers ... nothing there is
   long — no coats, no robes, no dresses, no long trousers`。
   `torso` 变量要写清「哪一件、什么颜色、什么形制、下摆到哪」。

## 四、制作记录必须与命令一致

Y02 的制作记录写着"人像 + 背景图1 + 香云纱马甲三图合成"，
但实际命令的第三张是「内搭参考」。**记录是凭记忆写的，没有核对实际命令。**

规则：制作记录里的每一行参数，都必须能从日志/命令回读出来。写不出命令行的参数不要写。
