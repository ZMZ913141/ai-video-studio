# 引擎默认值审计（2026-10-31）

> 起因：珠珠卡出片时连环踩到「引擎默认值里混着上一个客户的事实」——
> TTS 参考音写死 `cb_ref.wav`、提示词骨架写死 `his seated posture / in his chair`。
> 用户要求：**不是单次改，是把这类错误从机制上根除**。
> 本文是第二轮的**全量排查记录**，可作为以后接新客户前的 checklist。

## 一、判据（比清单重要）

> **只要骨架或默认值里出现一个「跟具体 IP 无关的具体事实」，它就是隐患 ——
> 哪怕当前所有 IP 恰好都符合。**

反例最能说明问题：`in his chair, hands near his lap` 对主号（坐姿财经口播）完全正确，
所以它活了很久；珠珠站姿一出片，同一段提示词就自相矛盾
（subject 写 "her seated posture"、detailed 写 "standing"），模型被两句话拉扯，站姿在段间漂。

**"当前都对"不是"永远都对"。**

## 二、扫描口径

扫 `templates/scripts/` + `bin/` 下所有 `.py`，9 类词表：

| 类别 | 命中说明 |
|---|---|
| 家具/场景 | lounge / sofa / chair / desk / wardrobe / showroom / office … |
| 性别 | he / his / she / her / man / woman / male / female |
| 服装 | shirt / jacket / vest / tie / glasses / embroidery / frog button … |
| 颜色/材质 | beige / cream / marble / oak / leather / silk / linen |
| 身份/职业 | presenter / host / anchor / boss / shop owner / founder |
| 语言 | Mandarin / Chinese / Cantonese / English |
| 具体人名/IP 名 | 现有档案名、别名、素材前缀（`cb_` 等） |
| 写死路径/文件名 | `/cfu/`、`.png/.wav/.mp4` 等 |
| 硬编码数字 | 88 BPM、3.6s、0.84、-16 LUFS |

**误报集中在这几个词，别照着词表改代码**：

| 词 | 为什么会命中 | 结论 |
|---|---|---|
| `anchor` | 标题位置（top/third/center/lower） | 误报 |
| `watch` | `comfy_guard.py watch` 守护命令 | 误报 |
| `studio` | `ip-studio` 模块名 / `COMFY_IN/studio` 目录 | 误报 |
| `presenter` | 中性词，本来就是为了不写死 | 误报 |
| `/cfu/ComfyUI`、ffmpeg 绝对路径 | 单机环境固定值 | 保留 |

## 三、真污染，已拆（8 处）

| # | 位置 | 原来 | 改成 | 不修会怎样 |
|---|---|---|---|---|
| 1 | `gen_video` `posture` | 无此变量，骨架写死 `his seated posture` | 变量，默认 `his posture` | 站姿 IP 被要求"按静帧的坐姿" |
| 2 | `gen_video` `rest_pose` | 骨架写死 `in his chair, ... near his lap` | 变量，默认 `settled and relaxed, hands resting low and still` | 站着讲的人被要求手放在腿上 |
| 3 | `gen_video` `pose_verb` | 骨架写死 `sits` | 变量，默认 `is` | summary 说"sits"、画面站着，两句话打架 |
| 4 | `gen_video` `lap_ref` | 手势库写死 `near his lap` | 变量，默认 `his lap` | 站立 IP 的默认手势出现"手在腿边" |
| 5 | `gen_video` `seated_where` | 默认 `seated in the room...` | 默认 `in the room...` | 新 IP 不填就继承"坐着" |
| 6 | `gen_video` `<d>[Chinese]` | 焊死 `[Chinese]` | `$lang_tag`（默认 `Chinese`） | 英文/粤语 IP 的口型标记与发音不一致 |
| 7 | `newip` 模板 | 没有 `gender` / `prompt_vars` | 两者必填 + 中性 `_todo` | **漏填不报错**，新客户悄悄继承上个客户的设定（gender 漏填 = 女性 IP 全篇 his） |
| 8 | `newip` `_todo` | "这些是从洁斌抄来的起始值" | "这些是引擎中性起始值（不是为任何 IP 定过的）" | 会写进每个客户卡的 ip.json |

另两处**非人物类**的写死（同样会坑客户，但优先级低）：

| 位置 | 原来 | 改成 | 说明 |
|---|---|---|---|
| `make_srt_asr` `language` | 写死 `Chinese` | `ASR_LANG`（env，默认 Chinese） | 外语素材会被识别成音近汉字，**时间轴还看着"对"**（按声学切的），最难查 |
| `make_bgm` `BPM` | 写死 `88.0` | `BGM_BPM`（env，默认 88） | 88 是"温暖抒情口播"的节奏，快节奏带货/严肃财经都不合适 |
| `studio_ai` 示例 | "To say no glasses, write `He wears no glasses` → WRONG; write `His face is unobstructed`" | 去掉具体人物细节，只讲规则 | **给模型的示例会被当模板照抄**（2026-10-30 踩过：翻译模板里的 `His hands...` 被抄进每一段） |

## 四、机制（防止下一轮再犯）

1. **运行时**：`voice_check.py` 进 pipeline 的 `voicetone` 步骤 —— 配音不像本 IP 就停片，并点名"最像哪个 IP"。
2. **同步前**：`scripts-sync` 入口跑 `bin/scripts_lint.py`
   - R1：IP 私有标识被拼进路径/赋值 → **阻断**
   - R2：「只判 exists 就跳过」的写文件 → **阻断**（换了素材不生效）
   - R3：字面量文件名 / 说明文字提到 IP 名 → 提示
3. **建档时**：`newip` 模板里 `gender` 与 `prompt_vars` 显式列出，`_todo` 写明"必须按本 IP 定板"。
4. **lint 基线归零**：R3 已收紧为"纯字面量文件名"（`ref_%s.wav` 这种按哈希命名不再误报）。
   **基线干净 = 以后出现任何一条告警都是真问题**，不再当噪音忽略。

## 五、验证方法（改默认值必须做）

改默认值属于"影响出片的东西"，必须证明**已交付的片子逐字节不变**：

```bash
# 改之前存基线
SRT=... AUDIO=... TAG=S01 DRY=1 python3 gen_video.py > /tmp/before.txt
# 改之后比对
SRT=... AUDIO=... TAG=S01 DRY=1 python3 gen_video.py > /tmp/after.txt
diff /tmp/before.txt /tmp/after.txt    # 必须为空
```

本轮结果：
- 主号 S01（9 段 / 240 行提示词）→ **diff 为空**
- 珠珠 Y01 → `standing in the white showroom` / `her standing posture` /
  `stands in the white showroom` / `on her feet` 各 8 次；
  `seated` / `in his chair` / `his lap` 各 **0** 次
