# 音色识别：本机能做什么、还缺什么

> 2026-10-29 实测。结论先说：**模型你已经有了，缺的只是一个能"喂音频"的壳。**

## 一、先分清两件事

| 要做的事 | 现在能不能 | 靠什么 |
|---|---|---|
| 量出音色的**客观特征** | ✅ 已经能用 | `bin/voice_profile.py`，纯标准库 + ffmpeg |
| 说出音色的**质感**（沙哑/清亮/气声） | ⚠️ 缺运行器 | 需要 Qwen2.5-Omni（权重已在盘上） |

客观特征包括：基频 F0、时长、响度、静音占比、音节率。
主号参考音实测：**F0 = 105.3 Hz**（男声区间，基于 58 个有效浊音帧，范围 86–214Hz）、
8.64s、−32.1 dBFS、静音 54% —— 这些数不会骗人，但说不出"嗓子有点哑"。

## 三、两条路，推荐第一条

### 路 A：llama.cpp（推荐）

理由：模型是 GGUF，直接吃；显存占用 ~10GB，**不和 H3 出片抢**（可以排队跑）；
一个命令行工具，没有 ComfyUI 的节点依赖漂移问题。

```bash
# 1) 二进制（Ubuntu 26.04 + CUDA 13.4 刚好有官方包，不用编译）
mkdir -p /cfu/llama.cpp && cd /cfu/llama.cpp
curl -L -o llama.tar.gz \
  https://github.com/ggml-org/llama.cpp/releases/download/b11981/llama-b11981-bin-ubuntu-cuda-13.4-x64.tar.gz
tar xzf llama.tar.gz

# 2) 跑一次（第一次加载 9GB 约 20-40 秒）
./build/bin/llama-mtmd-cli \
  -m /cfu/ComfyUI/models/LLM/Qwen2.5-Omni-7B-GGUF/Qwen2.5-Omni-7B-Q8_0.gguf \
  --mmproj /cfu/ComfyUI/models/LLM/Qwen2.5-Omni-7B-GGUF/mmproj-Qwen2.5-Omni-7B-Q8_0.gguf \
  --audio "/cfu/ai视频档案库/陈洁斌主号/02_素材真值/洁斌_声音参考_8s.flac" \
  -p "听这段录音，描述说话人的音色质感。" -n 256 -ngl 99
```

跑通之后，项目里这条命令已经封装好了：

```bash
python3 bin/voice_profile.py <音频>          # 物理量 + 听觉描述
python3 bin/voice_profile.py <音频> --no-omni # 只量物理量（不加载 9GB）
```

脚本会自动在 `/cfu/llama.cpp/**/bin/`、`~/llama.cpp/build/bin/`、`$PATH` 里找
`llama-mtmd-cli`；也可以用 `VOICE_MTMD=/path/to/llama-mtmd-cli` 指定。

### 路 B：ComfyUI 节点 `ComfyUI-Qwen-Omni`

能在 ComfyUI 界面里拖节点、直接听音频。代价：
- Qwen2.5-Omni-7B 走 transformers 要 bf16，**吃满 16GB 显存**，
  和 H3 出片不能同时跑（排队等）；
- 节点依赖 `transformers` 版本，跟现有的 `ComfyUI-QwenASR`（要求 ≥5.13）容易打架。

所以：**想在图里玩选 B，想稳定批量建档选 A。**

## 四、为什么不让文本大模型"听"

当前 LLM 路由里只有**文本和图片**两种输入，没有音频通道。
如果硬把音频丢给一个听不见的模型，让它"描述这段录音的音色"，它一定会编 ——
而且编得很像真的（"低沉有磁性、略带沙哑"）。

后果比不给更严重：这段描述会被写进 `ip.json` 的 `voice`，TTS 照着它去克隆，
**等于给真人安了一个不存在的嗓子**，而且后面每条片子都错，且查不出来。

所以规则是：**听不见就不说**。物理量照量，描述留空，界面明确写"未运行"。

## 五、接进建档流程（待 ll 跑通后接）

现在建档第 1 步上传音频时，走的是 `studio_ai.analyze_materials()`
→ `probe_audio()` 物理测量 → LLM 把数值翻成人话。

等 `llama-mtmd-cli` 就位，只要在 `analyze_materials()` 里加一段：

```python
if os.environ.get("STUDIO_OMNI", "1") == "1":
    from voice_profile import omni_describe
    o = omni_describe(audio_path)
    if o.get("ok"):
        out["voice_human"] = o["fields"].get("一句话音色指令", "")
        out["voice_fields"] = o["fields"]      # 六项分开存，别压成一段话
```

`voice_fields` 六项：性别与年龄段 / 音区与音色质感 / 语速与节奏 /
口音或地域特征 / 情绪与说话姿态 / 一句话音色指令。
写进 `ip.json` 的 `voice.describe`，TTS 提示词直接引用。
