## 一、三条硬规矩（违反就是废片）

### 1. 英文正文里，一个汉字都不能有

出片提示词的骨架是英文。混进去的汉字，模型**不会**当描述读，而当「画面上该出现的
字」—— S04 那一版就是这么被烧上去一整行字幕的。

只有这些可以保留原语言：

- 用户原始对白 / 台词
- 歌词
- 品牌名、UI 文案
- **画面里确实要显示的文字**（这类必须显式声明，不能偷偷混进来）

### 2. 只能用正向描述，禁止否定词

禁：`no` / `not` / `never` / `without` / `avoid` / 不要 / 不许 / 别

生成模型对否定式处理不可靠 —— 写「别皱眉」，它可能真给你皱眉。
「不要皱眉」要写成：`His brows rest level and relaxed.`

### 3. 只写画面上看得见的事实

写：眉的状态、眼的朝向、嘴的开合、手势幅度、身体动作、机位、光线。

不写：抽象评价。「专业」「亲和」「有感染力」这类词模型接不住，
要落成具体的脸部和手部状态。

## 二、H3 提示词结构（官方核心 Skill）

核心 `h3-prompt-writing` 管的是所有任务**共用**的部分，它不是某种视频风格：

| 部分 | 说明 |
|---|---|
| 官方字段 | H3 原生字段名，照官方定义来 |
| 任务类型 | T2VA / I2VA / FL2VA / L2VA / Ref2VA / Hybrid |
| 时间线 | `[Shot N]` 分镜；时间戳 / 毫秒时间码 |
| 素材标签 | Ref2VA 里 Subject / Picture / Video 的实际角色 |
| 声音合同 | 见下节 |

### 任务类型对照

| 类型 | 含义 | 需要什么 |
|---|---|---|
| `T2VA` | 文生视频 | 只要提示词 |
| `I2VA` | 图生视频 | 一张起始图 |
| `FL2VA` | 首尾帧 | 首帧 + 尾帧 |
| `L2VA` | 延长 | 已有视频片段 |
| `Ref2VA` | 参考生成 | Subject / Picture / Video 参考 |
| `Hybrid` | 关键帧＋参考混合 | 首帧和/或尾帧，另需至少一张参考图或一个参考视频 |

### 说话人标记（新版核心规则）

- 按**目标视频首次真实发声的顺序**分配：第一个开口的是 `(S1)`，第二个 `(S2)`
- 多人同时说话：`(S1,S2)`
- 跨切镜的连续对白：在**两侧**都加 `<scenetrans>`
- 只在**片尾截断**时用 `<cutoff>`（中间截断不用）
- Ref2VA 里普通视频自带的声音，**不能**被伪装成独立的 Audio 素材

## 三、声音合同（Sound Contract）

声音部分跟画面一样走英文：

- 说话人编号跟画面里的 `(S1)` **严格对应**
- 只描述能听见的：人声、环境音、音效、音乐
- 不描述「氛围」这类抽象词，落成具体的声音事件
- 音量 / 远近要跟画面机位一致（近景＝近声，远景＝远声带混响）

---

## 四、Qwen Image 2.1 的英文图像观察合同

Qwen Image 2.1 用**独立的一套英文图像观察合同**，跟 H3 的视频字段不混用：

- 输入：文字提示词 + 最多 **1–10 张有序参考图**
- 多图时用 `<imageN>` 明确指明来源（`<image1>` = 第一张）
- 比例：可跟随目标原图的真实宽高比；固定 UI 比例优先
  - `auto` 不强加比例（例如原图 1080×1590 → 输出 `36:53`）
  - 不会自动近似或裁剪 —— 下游支不支持要自己确认
- 透明模式：只要求 RGBA + Alpha 通道 + 透明背景的语义，不生成图片
- 默认模型：`qwen/qwen3.8-flash-next`

★ **协议隔离**：H3 用官方字段 / 任务类型 / 时间码；Seedance 2.0 用任务意图 +
`镜头N` 事件顺序；Qwen Image 2.1 用英文图像观察合同。**三套互不混用。**

## 六、落到本项目

| 文件 | 角色 |
|---|---|
| `05_文案/<套次>/prompts.json` | 中文分镜稿（人看的，可改） |
| `05_文案/<套次>/prompts.en.json` | 英文转写，**出片只认这份** |
| `bin/prompts.py` | `--gen` 生成 / `--optimize` 优化 / `--to-en` 翻译 |
| `bin/gen_video.py` | 只在 prompts.en.json 存在时采纳，按段覆盖默认英文描述 |

★ 改了中文稿 → **必须重跑 `--to-en`**，否则出片用的还是旧的英文分镜，
画面不反映你的改动（这是最难查的一类假片）。

翻译前后都过红线校验（`prompt_guard`）：含汉字 / 有否定词 → 整批不落盘，
宁可留着旧版，也不写半成品。
